# Command Center

Публичная демонстрация рабочего места управления на синтетических данных.
Интерфейс: команда, доступы, сроки действия, контроль списаний Project Ruler,
релизы, риски, стенды, знания и каталог ссылок Grafana.

Сайт работает без серверной части. Записи сохраняются только в браузере
посетителя и не становятся общей базой команды. Проверка тестового среза
Project Ruler и предпросмотр писем выполняются при открытой странице.
Корпоративные системы, корпоративный вход и отправка писем не подключены.
Используйте только вымышленные тестовые данные.

Визуальный стиль — самостоятельная адаптация с синей и оранжевой палитрой,
а не официальный сервис или подтверждённый брендбук ПСБ.

## Публикация

В настройках репозитория откройте **Settings → Pages**, выберите
**Deploy from a branch**, ветку **main** и папку **/(root)**. Сохраните.
После успешной сборки GitHub Pages покажет адрес сайта.

Для репозитория проекта адрес имеет вид
`https://<owner>.github.io/<repository>/`. Относительные пути поддерживают
как этот вариант, так и публикацию в корне личного сайта.

Здесь находятся только статические файлы, сгенерированные примеры данных
и безопасные общие пояснения. Исходные внутренние документы, рабочая база,
сервер Python и секреты в пакет публикации не входят.

GitHub Pages размещает статические HTML, CSS и JavaScript. Фоновые проверки,
получение корпоративных данных и рассылка потребуют отдельного сервера
в разрешённом рабочем контуре.
[Документация GitHub Pages](https://docs.github.com/en/pages/getting-started-with-github-pages/what-is-github-pages).
